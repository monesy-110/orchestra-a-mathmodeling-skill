# orchestra-a-mathmodeling-skill
Orchestra 是一款面向数学建模竞赛的工程化编排系统。 它将题意研判、模型构建、真实计算、证据可视化、论文写作与提交验收组织为七个环环相扣的乐章：论文里每个数字都能被自己的程序复现，上游证据一旦断裂，就回退修复而非文字润色。  项目以"证据优先"为指挥信念，提供三档演出状态——baseline 排练保流程稳定、enhancement 变奏做受控返工、championship 彩排在提交前执行多轮独立审稿。全流程可执行、可恢复、可审计，支持 CUMCM、51MCM、MCM/ICM 及 LaTeX、DOCX 双路线，优先适配 Codex 等 Skill 环境。  它不承诺获奖，只承诺：过程可解释、结果可复现、论文有据可循。
